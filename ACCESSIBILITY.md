# Accessibility

BDS Omni Manager aims to keep its interface usable with keyboard navigation, visible focus indicators, associated labels, readable contrast on a pure-black background, responsive layouts, and reduced-motion preferences.

The application is tested at desktop and narrow/mobile viewport widths. Some complex SVG graphs and dense server data views may still be harder to navigate with assistive technology; report specific barriers through a GitHub issue without including private server data.

Accessibility feedback is welcome. Please include the browser, assistive technology (if relevant), viewport size, and the steps needed to reproduce the barrier.
