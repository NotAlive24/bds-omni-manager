# Support

## Before asking for help

1. Check the [README](README.md), especially **Important process-control boundary**, **Backup safety**, and **What this release does not claim to do**.
2. Confirm the BDS Omni Manager version and Python version.
3. Check whether BDS was launched by the manager or by another service/wrapper. The manager cannot attach to an arbitrary external BDS console.
4. Reproduce the issue with a copy/test world where possible.

## Where to ask

- Reproducible bugs: open a GitHub **Bug report** issue.
- Feature ideas: open a **Feature request** issue.
- Usage questions: use GitHub Discussions if enabled by the repository owner.
- Security concerns: follow [SECURITY.md](SECURITY.md); do not post them publicly.

## What to include

- BDS Omni Manager version.
- Linux distribution/version and Python version.
- BDS version, if known.
- Whether the server is managed or externally launched.
- Exact steps, expected result and actual result.
- A short, redacted relevant log excerpt.

Never upload worlds, backups, `bedrocknode-token.txt`, account credentials, XUIDs, player data, or unredacted IP addresses/private paths.
